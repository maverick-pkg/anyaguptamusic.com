# Anya — Official Artist Site

Single-page official website for Anya, modeled on label-built artist sites
(tatemcrae.com, madisonbeer.com, oliviarodrigo.com).

## Status

Design-direction phase: three candidate variants live in `variants/`
(midnight / scrapbook / gloss). Once a direction is chosen, it becomes
`index.html` and real content replaces the placeholders.

## Placeholder content to replace

- Artist display name (currently "ANYA") — confirm spelling/casing
- Song titles, release years, cover art
- Show dates and venues
- Bio text and photos
- Booking email (currently booking@anyamusic.com)
- Streaming/social links (all currently `href="#"`)
- Mailing-list form provider (currently non-functional)

## Deployment target

GitHub Pages with the family's existing custom domain.
